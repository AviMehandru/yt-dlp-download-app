Queue & history

      
The queue runs strictly one at a time. Independent ytdl invocations
        race on global_manifest.json, the channel manifests and the Channel Info refresh
        throttle — --workers is the supported way to get parallelism, because it
        enumerates every video up front and postprocess.ps1 has matching file locking.

        racing it from a GUI is exactly the collision this pipeline is built to avoid.
